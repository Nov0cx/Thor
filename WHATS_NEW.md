# 2026.11.0

- **Settings are Lua now.** `settings.lua`, `keybinds.lua`, themes and plugin manifests are Lua files. Your old `.json` files were converted and kept as `.json.bak`.
- **Up to six panes.** View > "Pane Layout..." picks a layout, `ctrl+1` … `ctrl+6` focus a pane.
- **The Odin analyzer is back**, built in: hover, completion, signature help, go to definition, references, rename, inlay hints, quick fixes (`ctrl+shift+u`) and errors marked while typing.
- **Theme window**: a live preview, a palette generator, and edits that write nothing until Save.
- **Clipboard history**: `ctrl+shift+v` pastes one of the last 30 copied texts.
- **Plugin and theme updates**: the puzzle button in the title bar shows what can update.
- **Tutorial**: Help > Tutorial is a guided tour of the editor.
- **Markdown preview** renders like GitHub, with highlighted code blocks and text selection.
- Syntax highlighting for assembly (GAS, NASM, MASM, FASM).
